# 테스트 문서·문장 출처

네 기능을 실측할 때 넣을 입력을 어디서 구하는지 정리했다. 기관 메인 주소는 확실하고,
**게시판 깊은 주소는 바뀔 수 있다** — 안 열리면 메인에서 메뉴로 찾는다.

받은 파일은 `Test/data/<기능>/` 에 넣는다(커밋하지 않는다 — `Test/data/README.md`).

### 글다듬이

공개된 원문이 거의 없다(메일·게시글·고객발송문구·연체 사유·심사역 의견은 내부 글이다).

1. **고객사에서 익명화 샘플을 받는다** — 가장 좋다.
2. 받기 전까지는 **직접 만든다** — 문서유형 5종마다 3~5개, 일부러 거칠게(구어체 섞기 · 맞춤법 오류 ·
   장황함 · 존댓말 오락가락). 표가 든 글 1~2개를 섞어 디스클레이머가 나오는지도 본다.
   이름·전화·주민번호·계좌는 **가짜 값**으로 넣는다(PII 점검도 같이 탄다).
   LLM 으로 초안을 만들면 사람이 한 번 더 거칠게 손본다 — 같은 모델이 쓰고 다듬으면 너무 쉬운 입력이 된다.
