# 보류 설계 — pdf 표·좌표를 **PyMuPDF 구조 API** 로 직접 뜬다

> **상태: 착수 전(보류).** 실물 pdf 규정집의 **파일 용량이 확인되면** 그때 설계를
> 확정한다 (2026-09-03, 사용자 지시). 코드는 한 줄도 안 건드렸다.
>
> **"이제 뭐 하면 되나" 를 물으면 이 문서를 꺼낸다.**

---

## 1. 지금 무엇이 문제인가

pdf 는 첨부용 경로로 간다 — `PyMuPDFLoader` 가 **페이지마다 평문 한 덩어리**를 내고
문자 수로 자른다. 그래서:

| 증상 | 어디서 생기나 |
|---|---|
| 표 격자가 문장으로 풀린다 | **로더 단계**. 뒤에서 되살릴 방법이 없다 |
| 스캔 pdf 는 빈 청크 | 텍스트 레이어가 없다. **오류가 안 난다** |
| 조 한가운데가 잘린다 | 문자 수 분할 (위계 청킹이 켜지면 완화되지만 표는 그대로) |
| 머리말·꼬리말·2단 조판이 본문에 섞인다 | 평문에는 좌표가 없다 |

이 전처리기를 만든 이유(요구사항 §5 "표 깨짐")가 **pdf 에서 그대로 재현된다.** 오류가
아니라 "표를 물어봤는데 답이 이상하다" 로만 드러난다.

## 2. 왜 지능형이 아닌가 (2026-09-03 확정)

**지능형은 배제한다.** 폐쇄망이라 외부 API 를 못 쓰고, 지능형은 사이트 설치본 판본에
묶여 있어 이미 한 번 **hwpx 아닌 전 형식을 거부**하는 형태로 터졌다. 품질은 **설치
가능한 라이브러리 + 우리 코드**로 깎는다. 근거는 `preprocessor/CLAUDE.md` 의
"지능형은 걷어냈다" 절.

## 3. 설계 — 손댈 자리는 어댑터 하나다

`PyMuPDF`(fitz)는 **첨부용이 이미 쓰는 패키지**다 — 새 의존성이 0개다.

```
page.find_tables()      → 표 격자        → Block(kind="table", text=한 줄 HTML)
page.get_text("dict")   → 블록·스팬 좌표 → Block(kind="paragraph", ...) + bbox
```

만든 `Block` 을 **지금 있는 층에 그대로 흘린다**: `annotate_outline` → `chunk_blocks`.
그러면 **표 분할(머리행 반복·긴 칸 `<br>` 경계·`…` 표식·머리말 예약)과 조/항/호 위계가
공짜로 붙는다.** 새로 만들 규칙이 없다.

- **자리**: `final_preprocessor.py` PART 3 의 `_fp_langchain_blocks` (첨부용 최상위 경로).
  지금은 `Document.page_content` 를 줄 단위로 가르기만 한다.
- **`origin` 규약은 그대로**다 — 청크가 어느 `Document` 에서 나왔는지를 잃으면 벤더
  `compose_vectors` 가 못 돈다(`Chunk.origin` 이 비면 벤더 청커로 폴백).
- **bbox 를 얻는 김에** `chunk_bboxes` 를 진짜 좌표로 채울 수 있다 — hwpx 가 구역을
  페이지 자리에 넣는 것(2026-09-03)과 달리 pdf 는 실제 페이지다.

## 4. 한계 — 미리 적어 둔다

- **무괘선 표**는 `find_tables()` 가 약하다(선 기반). 옵션(`strategy="text"`)이 있지만
  오탐이 늘어 **표가 아닌 문단을 표로 만든다** — 그쪽이 더 나쁘다.
- **병합 셀**은 격자 복원이 완전하지 않다. hwpx 처럼 `rowspan`/`colspan` 을 그대로
  옮기지 못하는 경우가 있다.
- **스캔 pdf 는 못 고친다.** OCR 이 필요하고 그건 별건이다 — 아래 §5.

## 5. 함께 할 것 (같은 파일을 지난다)

1. **빈 산출을 드러낸다.** 페이지 텍스트가 사실상 0 이면 지금은 조용히 빈 청크로 적재
   성공한다. `scanned_pdf_suspected` 를 로그·경고로 낸다 — 가장 싸고 즉시 효과가 있다.
2. **반복 머리말·꼬리말 제거**, **2단 조판 분리**. §3 에서 좌표가 이미 손에 들어온다.

## 6. 착수 전에 할 것 — **기준선**

실물 pdf 규정집 한 벌을 `data/` 에 넣고 현행 산출물(청크 수·표 유무·빈 페이지 수)을
덤프해 픽스처로 박는다. **지금은 "떨어진다" 를 숫자로 말할 근거가 저장소에 없고**,
고친 뒤 나아졌는지도 못 잰다. `check_final_preprocessor` 에 그 픽스처를 붙인다
(대역이 아니라 실물로 — docling 대역을 꽂은 것과 같은 자리다).

**파일 용량이 여기서 걸린다** — 실물 pdf 를 저장소에 커밋할 수 있는 크기인지,
아니면 경로만 두고 `os.path.exists` 로 거를지(`_SAMPLES` 규약)를 정해야 한다.
