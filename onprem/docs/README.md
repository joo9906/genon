# onprem/docs — 문서 색인

`onprem/` 관련 문서가 어디에 있고 **무엇이 정본인지** 한 곳에서 본다.

## 배치 규칙 — 문서를 새로 쓸 때 어디에 두나

| 성격 | 위치 | 이유 |
|---|---|---|
| 그 디렉토리를 열었을 때 **처음 읽어야 할 것** | 해당 디렉토리의 `README.md` | 배포 단위·도구 폴더의 진입 문서. 자리를 옮기면 못 찾는다 |
| 한 기능의 **설계 심화** (구조·데이터 흐름·결정 근거) | `onprem/docs/<SFR>_*.md` | 길고, 코드보다 천천히 바뀌고, 여러 디렉토리에 걸친다 |
| **개발 규칙**(가이드 조항, 영역별 계약) | `genos-project/docs/GENOS_RULES.md` | 저장소 전체의 규칙 원본. 여기 복사하지 않는다 |
| 저장소 전체의 작업 지침 | 루트 `CLAUDE.md` | 어느 디렉토리를 고칠지 판단하는 진입 문서 |

**중복 금지.** 같은 사실을 두 곳에 적으면 한쪽이 낡는다. 배포·환경변수·운영 규약은
`onprem/README.md` 가 정본이고, 이 폴더의 문서는 거기를 **참조**한다.

## 이 폴더 밖의 문서 — 먼저 읽어야 할 순서

1. **루트 `CLAUDE.md`** — 저장소 구성, 우선순위(`onprem/` > `SFR-0xx/` > `genos-project/source/`),
   SFR-006 설계 결정 요약, 남은 일
2. **`genos-project/docs/GENOS_RULES.md`** — GenOS 개발가이드 강제 규칙 (영역별 시그니처,
   오류 코드 체계, 코드 서빙 배포 계약). **수정하려면 개발가이드 원문을 근거로 든다**
3. **`onprem/HANDOFF.md`** — 지금 무엇이 검증됐고 무엇이 막혀 있나 (이어 하는 사람의 첫 문서)
4. **`onprem/WORK.MD`** — **어떤 파일부터 쓰나.** 단계별 작성 순서·분량·완료 판정
5. **`onprem/README.md`** — 배포 단위(03 4 · 01 4 · 02 9 · 05 1), 옮기는 순서, 환경변수,
   로깅 규약, 코드서빙 실행
6. **`onprem/preprocessor/README.md`** — hwpx 전용 전처리기(area 05) 설계 결정의 정본
7. **`onprem/eval/README.md`** — 평가지표 MCP 서버 (배포 단위 아님)
8. **`onprem/test/README.md`** — 배포 계약 점검 스크립트 (배포 단위 아님)

기능별 원본 개발 사본의 문서는 `SFR-018/README.md` 에 있다.
