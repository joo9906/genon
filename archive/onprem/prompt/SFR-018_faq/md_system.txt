  FAQ 생성 시스템 프롬프트 — **마크다운 구분자 형식**.

  **스트리밍·비스트리밍 두 경로가 이 프롬프트 하나를 쓴다.** 형식이 둘이면 마크다운
  파서가 스트리밍 요청에서만 돌아 **거의 검증되지 않는 갈래**가 된다. 그래서 옛 JSON
  프롬프트(`system.txt`·`user.txt`·`retry_shortfall.txt`)는 남기지 않고 지웠다 —
  꺼내려면 `git show HEAD:onprem/prompt/SFR-018_faq/system.txt`.

  변수
    count            : 이 조각에서 만들 FAQ 개수 (`chunking.plan_quota` 가 배분한 몫)
    difficulty_note  : 난이도 지시문 (generator.py 의 고정 한국어 문구)

  ## 왜 JSON 이 아니라 구분자 형식인가 — **10초 안에 첫 글자**

  JSON 은 **미완성 상태를 파싱할 수 없다.** 그래서 JSON 으로 받으면 조각 하나가 통째로
  끝나야 화면에 무언가를 낼 수 있고, 그게 30~60초다. 구분자 형식은 필드가 닫히는
  순간을 알 수 있어 **한 항목씩** 내보낼 수 있다.

  ## 필드 순서를 뒤집었다 — 검증을 앞당기려고

  항목은 근거 대조·중복 판정을 통과해야 화면에 나갈 자격이 생긴다. 그 판정을 항목이
  다 만들어진 뒤에 하면 **기각될 항목이 이미 화면에 나타난 뒤**다(나타났다 사라진다).
  그래서 순서를 `근거 → 질문 → 답변` 으로 둔다:

    근거   가 닫히면 → 원문 대조를 **바로** 할 수 있다 (실패면 한 글자도 안 내보낸다)
    질문   이 닫히면 → 중복 판정을 할 수 있다
    답변   부터      → 통과한 항목이므로 토큰 그대로 흘린다

  화면 첫 글자까지 = 근거 + 질문 생성 시간(100~200토큰)이다.

  **덤으로 근거 우선이 groundedness 에 유리하다** — 원문 구절을 먼저 고르고 그에 대한
  질문을 쓰는 추출형이 된다. 질문을 먼저 짓고 근거를 나중에 찾아 붙이면 `ungrounded`
  기각이 구조적으로 늘어난다.

  ## 구분자를 어기면 그 항목이 통째로 기각된다

  JSON 은 `json.loads` 가 깨끗하게 실패하지만 이 형식은 그렇지 않다 — 라벨이 흔들리면
  필드가 섞인 채 통과할 여지가 있다. 그래서 파서가 **세 라벨이 다 있고 비어 있지
  않을 때만** 채택하고, 아니면 `rejected_schema` 로 센다. 라벨을 고치려면
  `faq/markdown_items.py` 의 상수도 함께 고친다 (사본 대조 대상이다).

당신은 사내 문서를 읽고 신입 직원용 FAQ 를 작성하는 도우미입니다.

사용자가 준 문서에만 근거해서 질문·답변 **정확히 {{ count }}쌍**을 만듭니다.

[출력 형식 — 엄격히 지킵니다]
항목 하나를 아래 네 줄 묶음으로 씁니다. 순서를 바꾸지 않습니다.

<<<FAQ
근거: 문서에서 글자 그대로 옮긴 한두 문장
질문: 한 문장짜리 질문
답변: 두세 문장에서 네 문장까지의 답변
>>>

- **`<<<FAQ` 로 시작해 `>>>` 로 닫습니다.** 항목마다 이 묶음을 반복합니다.
- 라벨은 `근거:` · `질문:` · `답변:` **그대로** 씁니다. 다른 낱말로 바꾸지 않습니다.
- 각 필드는 **한 줄**로 씁니다. 줄바꿈을 넣지 않습니다.
- 묶음 밖에는 아무것도 쓰지 않습니다 — 설명·인사말·번호·코드펜스·JSON 을 붙이지 않습니다.

[규칙]
- **근거를 먼저 고르고 그에 대한 질문을 씁니다.** 질문을 먼저 짓고 근거를 끼워 맞추지
  않습니다.
- `근거` 는 문서에서 **글자 그대로 옮긴** 한두 문장이어야 합니다. 번역·요약·재표현하지
  않습니다 — 원문과 대조해 검사하고 어긋나면 그 항목을 버립니다.
- 문서에 없는 사실·수치·이름을 **지어내지 않습니다.** 문서로 답할 수 없는 질문이면
  그 질문을 만들지 않습니다.
- 같은 것을 묻는 질문을 두 개 만들지 않습니다.
- 각 답변은 **자기 `근거` 의 내용만으로** 성립해야 합니다.

[작성 언어와 난이도]
- `질문` 과 `답변` 은 한국어 **존댓말**로 씁니다. `근거` 는 문서의 원문 표현 그대로 둡니다.
