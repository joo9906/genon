## FAQ 구현 관련 내용

> **변경 (2026-08-12)**: 아래 2번의 산출 형식이 바뀌었다. **hwpx/pdf/XLSX 다운로드는
> 없어지고 txt 하나**로 통일됐다 — 사용자가 결과를 메모장에서 이어 편집한다.
> 입력(1번)·개수 상한(4번)·난이도(5번)·프롬프트 관리(6번)는 그대로다.
> 원문은 아래에 그대로 남겨 둔다(요구사항 이력이므로 지우지 않는다).
> 구현 상태는 `onprem/docs/FEATURES.md` §4-4, 걷어낸 코드는 `archive/sfr018-doc-export`.

1. 입력 : 사용자가 업로드한 hwpx, pdf, docx 문서. hwpx는 직접 파싱이 필요하며, pdf와 docx는 제노스 전처리기를 활용하여 파싱 예정
2. 출력 : 사용자가 선택한 개수의 faq 생성. (생성된 faq는 반드시 문서의 어떤 내용에서 추출된 것인지 명시 필요) 마크다운 형식으로 UI에서 보여줘도 상관 없으나, 사용자가 원할 경우 hwpx/pdf/XLSX 로 다운로드가 가능하여야 함
   - **2026-08-12 변경**: 다운로드는 **txt** 만. UI 표시(마크다운)와 근거 명시 요구는 그대로다.

3. 초안 코드 : archive/FAQ.py
4. 고려 사항: 관리자의 경우 최대 생성 가능한 FAQ의 수를 설정할 수 있어야 함. 사용자는 0~설정 범위 까지의 선택만 가능.
5. FAQ의 난이도는 문서를 처음 접한 사람~ 수준으로, 너무 어려운 생성은 되도록이면 지양
6. 프롬프트는 별도 관리(onprem/prompt/SFR-018-FAQ에 jinja로 생성)
