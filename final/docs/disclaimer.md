# 안내 문구 (disclaimer) — Disclaimer MCP 환경변수 등록표

결과는 냈지만 사용자가 알아야 하는 것을 화면에 말하는 문장이다. **문장은 Disclaimer MCP 에서만 나온다.**
워크플로우 스텝은 언제 띄울지와 숫자만 정한다.

## 동작

- 스텝이 `widget_disclaimer(agent_id, disclaimer_id)` 를 부르면 MCP 가 환경변수
  **`MCP_TOOL_19_{agent_id}_{disclaimer_id}`** 의 값을 그대로 돌려준다.
  - `agent_id` — 요구사항 번호. 018 세 기능은 `SFR018`, 양식 채우기는 `SFR006`.
  - `disclaimer_id` — 아래 표의 번호.
- **MCP 에는 숫자를 넘길 자리가 없다.** 그래서 등록 문구에는 숫자를 넣지 않고, 숫자가 필요한 안내는
  스텝이 등록 문구 **다음 줄에 상세 줄**(`다듬지 못한 구간: 3곳`)을 붙인다.
- 문구를 못 받으면(MCP 미설정 · 호출 실패 · 빈 값) 맨 앞에 한 번
  `disclaimer를 확인하지 못하였습니다. 결과에 유의해 주세요.` 가 붙고, 상세 줄과 결과는 그대로 나간다
  (`event=disclaimer_unavailable`).
- 화면에는 네 기능 모두 result 의 **`disclaimer` 한 키**(문자열)로 나간다. 줄이 여럿이면 줄바꿈(`\n`)으로 잇는다.
- **내려받는 파일에도 들어간다.** 018 셋은 md 맨 위 인용 블록, 템플릿 채우기는 hwpx 맨 끝(LLM 이 쓴 본문 아래)이다.
  **`download_failed`(2)만 파일 밖**이라 화면 `disclaimer` 맨 뒤에만 붙는다. 파일 안 안내는 번호 순이다.
- 워크플로우 쪽 설정은 `DISCLAIMER_MCP_ID`(Disclaimer MCP 서빙 ID) 하나다.

번호를 바꾸거나 더할 때는 해당 스텝의 `_DISCLAIMER_NUMBERS` 와 이 표를 함께 고친다.

예 — FAQ 를 5개 요청했는데 3개만 근거가 확인됐을 때 `disclaimer`:

```
문서에서 근거를 확인할 수 있는 FAQ가 요청하신 개수보다 적게 만들어졌습니다.
2개를 생성하지 못하였습니다.
```

## SFR018 — 글다듬이 · 번역 · FAQ

번호는 세 기능이 함께 쓴다. 안내는 이 7종뿐이다.

| 환경변수 | 종류 | 쓰는 기능 | 언제 | 등록 문구 | 상세 줄 | 자리 |
|---|---|---|---|---|---|---|
| `MCP_TOOL_19_SFR018_1` | `scan_ocr` | 셋 다 | 첨부의 스캔 쪽을 OCR 로 읽었을 때 | 스캔 문서는 글자 인식(OCR)으로 읽었기 때문에 일부 내용이 원본과 다를 수 있습니다. 중요한 내용은 원본과 대조해 확인해 주세요. | 없음 | 파일 안 |
| `MCP_TOOL_19_SFR018_2` | `download_failed` | 셋 다 | 결과 md 링크를 만들지 못했을 때 | 결과를 파일로 만들지 못했습니다. 파일이 필요하시면 다시 시도해 주세요. | 없음 | **화면만** |
| `MCP_TOOL_19_SFR018_3` | `input_unusable` | 글다듬이 · 번역 | 다듬을(번역할) 만한 글이 아니라고 판단했을 때. 결과 · 원문 · 파일은 비우고 이 안내만 낸다 | 입력하신 내용에서 처리할 문장을 찾지 못했습니다. 문장을 입력해 다시 요청해 주세요. | 없음 | 화면 (파일 없음) |
| `MCP_TOOL_19_SFR018_4` | `fact_mismatch` | 글다듬이 · 번역 | 결과의 숫자 · 날짜가 원문과 다를 때 | 결과의 숫자·날짜가 원문과 다른 부분이 있습니다. 결과를 확인해 주세요. | `원문과 다른 곳: N곳` | 파일 안 |
| `MCP_TOOL_19_SFR018_5` | `structure_changed` | 글다듬이 · 번역 | 표 · 제목 등 구조가 원문과 달라졌을 때 | 표·제목 등 문서 구조가 원문과 달라진 부분이 있습니다. 결과를 확인해 주세요. | `구조가 달라진 곳: N곳` | 파일 안 |
| `MCP_TOOL_19_SFR018_11` | `translate_failed_units` | 번역 | 일부 문장 번역이 실패해 원문을 그대로 둔 경우 (전량 실패는 안내가 아니라 오류) | 일부 문장을 번역하지 못해 해당 부분은 원문 그대로 두었습니다. 다시 번역해 주세요. | `번역하지 못한 문장: N개` | 파일 안 |
| `MCP_TOOL_19_SFR018_31` | `faq_shortfall` | FAQ | 근거가 확인된 항목이 요청보다 적을 때 | 문서에서 근거를 확인할 수 있는 FAQ가 요청하신 개수보다 적게 만들어졌습니다. | `N개를 생성하지 못하였습니다.` | 파일 안 |

- 글다듬이 · 번역은 안내 판정(가드 MCP)이 서빙 응답 뒤에 끝나므로, 본 호출을 `upload=false` 로 하고 판정을 마친
  뒤 코드서빙 `POST /upload`(본문 · 제목 · 파일 안 안내문)로 올린다.
- FAQ 는 파일을 서빙이 생성 요청 안에서 굳히므로, 스텝이 1 · 31 문구를 생성 **전에** 받아 넘기고 낼지와 상세 줄은
  서빙이 정한다(`main._build_disclaimer`). 2 만 스텝이 뒤에 붙인다.

## SFR006 — 양식 채우기 (006-3)

| 환경변수 | 종류 | 언제 | 등록 문구 | 상세 줄 | 자리 |
|---|---|---|---|---|---|
| `MCP_TOOL_19_SFR006_1` | `scan_ocr` | 이번 턴에 스캔 문서를 OCR 로 읽어 실제로 채웠을 때 (이미 반영한 문서를 다시 실어 온 턴은 제외) | 스캔 문서는 글자 인식(OCR)으로 읽었기 때문에 일부 내용이 원본과 다를 수 있습니다. 채워진 내용을 원본과 대조해 확인해 주세요. | 없음 | hwpx 맨 끝 |
| `MCP_TOOL_19_SFR006_2` | `download_failed` | 다 채워 파일을 만들려 했는데 실패했을 때 (덜 채워 링크가 없는 것은 제외) | 작성한 문서를 파일로 만들지 못했습니다. 잠시 후 다시 시도해 주세요. | 없음 | **화면만** |

- 파일은 **다 채운 턴**에 서빙이 만든다. 그래서 스텝 3 이 1 의 문구를 그 턴(스캔 문서를 읽은 턴)에 받아
  `/chat/commit` 의 `file_disclaimer` 로 넘기고, 서빙이 세션(`file_disclaimer`)에 두었다가 이후 턴에 만드는 파일
  맨 끝에도 붙인다. 화면에는 읽은 그 턴과 **파일이 나온 턴**에 나온다 — 파일이 나온 턴은 서빙이 돌려준
  `file_disclaimer`(파일에 넣은 것 그대로)를 낸다.

## 그대로 붙여 넣을 등록 값

MCP 도구 환경변수 화면이 `MCP_TOOL_19_` 를 앞에 붙이므로 아래 이름 부분만 입력한다.

```
SFR018_1=스캔 문서는 글자 인식(OCR)으로 읽었기 때문에 일부 내용이 원본과 다를 수 있습니다. 중요한 내용은 원본과 대조해 확인해 주세요.
SFR018_2=결과를 파일로 만들지 못했습니다. 파일이 필요하시면 다시 시도해 주세요.
SFR018_3=입력하신 내용에서 처리할 문장을 찾지 못했습니다. 문장을 입력해 다시 요청해 주세요.
SFR018_4=결과의 숫자·날짜가 원문과 다른 부분이 있습니다. 결과를 확인해 주세요.
SFR018_5=표·제목 등 문서 구조가 원문과 달라진 부분이 있습니다. 결과를 확인해 주세요.
SFR018_11=일부 문장을 번역하지 못해 해당 부분은 원문 그대로 두었습니다. 다시 번역해 주세요.
SFR018_31=문서에서 근거를 확인할 수 있는 FAQ가 요청하신 개수보다 적게 만들어졌습니다.
SFR006_1=스캔 문서는 글자 인식(OCR)으로 읽었기 때문에 일부 내용이 원본과 다를 수 있습니다. 채워진 내용을 원본과 대조해 확인해 주세요.
SFR006_2=작성한 문서를 파일로 만들지 못했습니다. 잠시 후 다시 시도해 주세요.
```
