# 서비스 아키텍처

네 기능을 **입력 → 처리 단계 → 출력**의 한 줄 파이프라인으로 그린다.
프론트와 주고받는 값의 정본은 [`FRONT.md`](FRONT.md), 안내 문구는 [`disclaimer.md`](disclaimer.md),
환경변수는 [`env.md`](env.md) 다.
단계마다 안에서 무엇을 하는지(설정값 · 부르는 MCP)는 [`architect.html`](architect.html) 에 그렸다.

**단계 표시**

| 표시 | 뜻 |
|---|---|
| `●` | 우리 코드가 지금 한다 |
| `◎` | GenOS 플랫폼이 한다 (우리 코드 밖) |
| `◐` | 일부만 한다 — 오른쪽에 무엇이 빠졌는지 적었다 |
| `○` | 자리만 있다 — 지금은 이 단계 없이 다음 단계로 넘어간다 |

**공통 입출력** — 화면은 흘러오는 글 `token` 여러 번과 마지막 `result` 1회를 받는다.
알릴 것이 있으면 `result.disclaimer` 가 붙는다. 겨럧과 파일은 MinIO 에 올리고 `download_url` 로 준다.

## 1. FAQ 생성

```
  ┌──────────────────────────────────────┐
  │  입력   FAQ 개수 설정 + 파일 업로드      │  faq_count · faq_max_count · faq_title
  └───────────────────┬──────────────────┘
                      ▼
● 전처리기             high_preprocessor — hwpx·docx·pdf → 마크다운 (스캔 쪽은 OCR MCP)
                      ▼
◎ PII 마스킹           GenOS 가드레일(#315). final_preprocessor 에만 연결돼 있고 high 에는 없다
                      ▼
○ 입력 가드레일
                      ▼
● 문서 길이에 따른 분할  12,000자 조각
                      ▼
● FAQ 생성             조각마다 LLM, 6개씩 동시에 (항목마다 근거 → 질문 → 답변)
                      ▼
● 청크별 FAQ 합침       조각 순서대로 채택 — 형식 → 근거 대조(문서 전체) → 중복 제거 → 개수 상한
                      ▼
◐ 검증 및 평가 MCP      근거 대조는 위 합침에서 코드서빙이 한다. 평가 MCP(Test/eval)는 배포 밖에서만 돈다
                      ▼
○ 출력 가드레일
                      ▼
◐ 답변 품질 가드레일    개수 미달 · 초과 · 구간 누락을 안내로 알린다 (막지는 않는다)
                      ▼
  ┌──────────────────────────────────────┐
  │  출력   md 파일 + text 반환            │  token(문답 항목 단위) · result{faq_items, download_url}
  └──────────────────────────────────────┘
```

## 2. 글다듬이

```
  ┌──────────────────────────────────────┐
  │  입력   문서유형 · 톤 선택 + 글/파일     │  polish_doc_type · polish_tone
  └───────────────────┬──────────────────┘
                      ▼
● 전처리기             첨부가 있을 때만 (스캔 쪽은 OCR MCP)
                      ▼
◎ PII 마스킹           GenOS 가드레일(#315). 채팅에 붙여 넣은 글은 거치지 않는다
                      ▼
◐ 입력 가드레일         뜻 없는 입력만 막는다 (/input/check). 인젝션 · 금칙 표현은 안 본다
                      ▼
● 톤 정책              MCP resolve_tone — 문서유형이 톤을 강제하면 바꾸고 안내
                      ▼
● 문서 길이에 따른 분할  6,000자 조각
                      ▼
● 문장 다듬기           조각마다 LLM, 4개씩 동시에 · 다듬는 대로 화면에 흘림
                      ▼
● 청크별 결과 합침       문서 순서대로 이어 붙임
                      ▼
● 검증 MCP             text_guard — 표·제목 구조 · 숫자·날짜가 원문과 같은지
                      ▼
○ 출력 가드레일
                      ▼
◐ 답변 품질 가드레일    구조·숫자 어긋남 · 일부 조각 실패를 안내로 알린다
                      ▼
  ┌──────────────────────────────────────┐
  │  출력   md 파일 + text 반환            │  token(다듬은 글) · result{original_text, polished_text, download_url}
  └──────────────────────────────────────┘
```

## 3. 번역

```
  ┌──────────────────────────────────────┐
  │  입력   언어 · 문체 선택 + 글/파일       │  translate_target_lang · translate_source_lang · translate_register
  └───────────────────┬──────────────────┘
                      ▼
● 전처리기             첨부가 있을 때만 (스캔 쪽은 OCR MCP)
                      ▼
◎ PII 마스킹           GenOS 가드레일(#315). 채팅에 붙여 넣은 글은 거치지 않는다
                      ▼
◐ 입력 가드레일         뜻 없는 입력(/input/check) · 한국어 축이 아닌 언어쌍(MCP validate_direction)을 막는다
                      ▼
● 문서 길이에 따른 분할  6,000자 조각 (문단·표 단위로만 끊는다)
                      ▼
● 번역                 조각마다 LLM · 문서 순서대로 화면에 흘림
                      ▼
● 청크별 결과 합침       /translate/finalize — 이어 붙이고 용어사전 대조(한↔영) · <mark> 표시
                      ▼
● 검증 MCP             표 · 목록 구조 대조 · text_guard numeric_issues(숫자·날짜)
                      ▼
○ 출력 가드레일
                      ▼
◐ 답변 품질 가드레일    용어 미반영 · 구조 변경 · 숫자 불일치를 안내로 알린다
                      ▼
  ┌──────────────────────────────────────┐
  │  출력   md 파일 + text 반환            │  token(번역문) · result{original_text, translated_text, download_url}
  └──────────────────────────────────────┘
```

## 4. 템플릿 채우기 (여러 턴)

```
  ┌──────────────────────────────────────┐
  │  입력   양식 선택 + 채팅 (+ 참고 문서)   │  template_fill_template_id · 발화 · 첨부(선택)
  └───────────────────┬──────────────────┘
                      ▼
● 세션 불러오기         양식 항목 목록 · 지금까지 채운 값 (Redis)
                      ▼
● 전처리기             첨부가 있을 때만 (스캔 쪽은 OCR MCP)
                      ▼
◎ PII 마스킹           GenOS 가드레일(#315). 발화는 거치지 않는다
                      ▼
○ 입력 가드레일
                      ▼
● 발화 해석             LLM — 채울 값 · 지울 값 · 본문 추가 · "문서로 바꿔줘"
                      ▼
● 문서 길이에 따른 분할  12,000자 조각 (첨부가 있고 아직 안 읽은 문서일 때)
                      ▼
● 문서 자동 채움        1차 LLM 주제 목록 → 코드가 주제별 구간으로 자름 → 2차 LLM 주제마다 묶음 채움
                      ▼
● 청크별 결과 합침       문서 값 → 발화 값 순으로 병합 (사용자가 넣은 값은 덮지 않음)
                      ▼
● 검증                 항목 화이트리스트 대조 — 양식에 없는 항목 · 형식이 틀린 값은 버림
                      ▼
○ 출력 가드레일
                      ▼
◐ 답변 품질 가드레일    자동 채움 일부 실패 · 파일 생성 실패를 안내로 알린다
                      ▼
  ┌──────────────────────────────────────┐
  │  출력   hwpx 파일 + text 반환          │  token(진행 → 답변 → 미리보기) · result{text, download_url, session_id}
  └──────────────────────────────────────┘
```

`download_url` 은 다 채웠을 때만 온다. 그 전에도 화면이 `POST /generate` 로 받을 수 있다.
