# 단위 테스트 돌리기

## 무엇을 옮기나

`final/`·`no_pythonstep/`·`Test/` 세 폴더를 **같은 부모 폴더 아래 나란히** 둔다. 테스트가 `Test/` 의 부모를 저장소 루트로 보고 나머지 둘을 찾는다.

```
<아무 폴더>/
  final/           # MCP · 워크플로우 · 전처리기 · 006(기본)
  no_pythonstep/   # 코드서빙 — 젠포탈이 POST /chat 을 직접 부른다 (018 셋, 006 은 전환 시)
  Test/
```

- 018 세 단위(번역·글다듬이·FAQ)는 **`no_pythonstep/`** 을 본다.
- 006(템플릿 채우기)은 기본이 **`final/`** 이고, `--006=no_pythonstep` 을 주면 그쪽을 본다.
- unittest 는 이 세 폴더만 있으면 돈다. LLM·Redis·GenOS 는 필요 없다. 테스트가 대역을 꽂는다.
- 점검 중 **`check_final_preprocessor`·`check_smart_preprocessor` 둘은 `archive/` 도 있어야 한다.**
  실물 hwpx(`archive/data/`)와 벤더 참조 사본(`archive/genos_files/`)을 읽기 때문이다.
  없으면 그 둘만 FAIL 이고 나머지는 통과한다.

## 준비

Python 3.10 이상(3.13 에서 확인). 네 단위의 `requirements.txt` 를 설치한다. 합치면 아래 7개다.

```
pip install "fastapi>=0.110" "uvicorn>=0.30" "pydantic>=2.6" "httpx>=0.27" "python-multipart>=0.0.9" "redis>=5.0" "lxml>=5.0"
```

## 실행 (`Test/` 의 부모 폴더에서)

```
python Test/run_all.py                       # 전부 (006 = final)
python Test/run_all.py --006=no_pythonstep   # 006 도 no_pythonstep 으로
python Test/run_all.py SFR-006 SFR-018       # unittest 만
python Test/run_all.py chat_direct           # /chat 직접 호출 점검만
```

| 006 출처 | 대상 | 통과 표시 |
|---|---|---|
| `final` (기본) | 점검 17 + unittest 2벌 | `19/19 통과` |
| `no_pythonstep` | 위 + 006 `/chat` unittest(`SFR-006-chat`) | `20/20 통과` |

건수가 기준(`Test/run_all.py` 의 `EXPECTED`·`EXPECTED_BY_006`)보다 적어도 FAIL 이다.
`check_high_preprocessor` 는 `docling_core` 가 없으면 hwp 17건이 빠져 73/90 으로 FAIL 이 난다(환경 문제).

## 실패 상세 보기

`run_all.py` 는 요약만 찍는다. 실패한 테스트의 내용은 그 폴더에서 직접 돌려 본다.

```
cd Test/SFR-018
python -m unittest discover -s tests -t . -v
python -m unittest tests.test_chat_input -v      # 파일 하나만

cd Test/SFR-006
$env:GENON_SFR006_SOURCE="no_pythonstep"          # PowerShell — 006 을 no_pythonstep 으로
python -m unittest discover -s tests_chat -t . -v
```

Windows 콘솔에서 `UnicodeEncodeError` 가 나면 먼저 인코딩을 지정한다.

```
$env:PYTHONIOENCODING="utf-8"     # PowerShell
set PYTHONIOENCODING=utf-8        # cmd
```
