# genon

## 평가지표 공통 원칙

- **결정적(코드) 지표 우선, LLM Judge 는 최소화.** 재현성·비용·지연·비결정성 때문에,
  LLM Judge(생성형 판정)는 **결정적·임베딩 지표로 못 잡는 항목에만, 그것도 결정적
  스크리닝을 통과 못한 건에 한해 샘플링/opt-in** 으로만 쓴다. 전건(全件) 상시 호출 금지.
  임베딩 유사도는 고정 모델의 결정적 벡터 연산이라 여기서 줄이려는 '생성 LLM 호출'과
  구분한다. LLM Judge·임베딩 모델을 실제로 켤 때는 온프레미스 서빙 가용성을 먼저 확인한다.
- **참조(정답) 데이터가 필요한 지표와 아닌 지표를 구분**해 적는다 — 참조가 없으면
  측정 불가능한 지표를 운영 지표로 잡지 않는다.

## 006 평가지표 (HWPX 템플릿 채우기)

> 006 은 문서 변환이 아니라 **누름틀 텍스트 치환**이다. lxml 로 필드 run 만 수정하므로
> 레이아웃·표 구조는 설계상 불변 → 렌더링 기반 지표(BBox IOU, TEDS)는 측정 수단(HWPX
> 렌더러)도 없고 측정할 대상도 아니라 제외. 대신 XML 레벨에서 무결성을 검증한다.

1. **필드 추출 정확도** (LLM 구간 — 파이프라인의 유일한 비결정 구간)
   - 사용자 발화 → `{필드명: 값}` 추출의 필드별 precision / recall / F1
   - 값 정확도: 정답 값과 exact match (정규화 후), 부분 일치는 별도 집계
   - 환각률: 템플릿에 없는 필드명 생성 비율 (화이트리스트 기각 건수로 측정 — 이미 로그 노출됨)
2. **채움·판정 정확성** (결정적 구간 — 회귀 테스트로 검증)
   - 라운드트립: 채움 → 재스캔 시 채워짐/부족 판정 일치율 100% 유지
   - 값이 없는 필드는 안내문 상태로 남는지 (부분 초안 계약)
3. **문서 무결성**
   - Text recall: 원본 텍스트 누락 없음 + 원본에 없는 텍스트 추가 없음
     (필드 값 제외 영역은 XML 트리 비교로 판정)
   - 개체 수 일치: 이미지·표 등 타입별 개수 (XML 요소 카운트)
   - 산출 hwpx 가 한/글에서 정상 열림 — 실제 한/글 템플릿 확보 후 수동 스팟체크
4. **E2E 멀티턴 시나리오**
   - 시나리오별 최종 완성 성공률, 완성까지 턴 수
   - 세션 누적 정확성: 이전 턴 값 유실·덮어쓰기 오류 없음

## 018 평가지표 (글다듬이 / 번역 / FAQ)

### 공통 — 구조 보존 (이 저장소의 핵심 계약)

- **번역**: 스켈레톤 분리·재조립이 구조를 보장하므로, 지표는 **재조립 실패·세그먼트 수
  불일치로 인한 fallback 발생률** (0 에 수렴해야 함)
- **글다듬이**: `markdown_guard.py` 지문 대조 **통과율** (마크다운/HTML 표 행·셀,
  제목, 코드펜스 훼손 감지)

### 1. 톤 적합성 (글다듬이)

- 어미·조사 처리, 축약·관용 표현 (문서유형×톤 프리셋 대비) — 규칙 기반 검사
- 어미(~다/~했습니다) 문서 초반·후반 일관성 검사
- 문장 길이·품사 비율(PosTagging)은 참고 지표로만 — 합불 기준으로 쓰기엔 문서별 편차가 큼
- LLM Judge 미사용 — 톤은 위 규칙 기반 검사로 합불한다. 주관적 편차가 커서
  생성형 판정을 상시로 붙일 실익이 낮다 (필요 시 수동 스팟체크로 대체).

### 2. 의미·사실 보존성 (글다듬이·번역 공통)

- **결정적 검사 우선**: 숫자·날짜·단위·고유명사(NER) 추출 후 원문·결과 교차 대조,
  불일치 시 감점 — 이게 1차 방어선이자 운영 지표
- 결정적 검사로 못 거르는 재서술 수준 누락·왜곡은 **임베딩 유사도로 1차 스크리닝**,
  임계 미달 건만 **NLI LLM Judge 로 샘플링 확인** (전건 호출 아님 — opt-in)
- 역번역 검증은 제외 — 오류 원인(번역 vs 역번역) 분리 불가, 비용 2배 대비 판별력 낮음

### 3. 번역 품질

- **참조 번역이 있는 테스트셋**: chrF(우선, 한국어에 BLEU 보다 안정적) + BERTScore
- **참조가 없는 운영 입력**: 다국어 임베딩 원문·번역본 유사도(결정적)를 기본 운영 지표로,
  유사도 하위 구간만 LLM Judge 로 샘플링 확인 (전건 호출 아님)
- **용어집 준수율**: 용어집 원문 용어 등장 시 지정 번역어 사용 비율 (결정적 검사,
  genos-glossary 실험의 판정 기준)

### 4. FAQ 원청 정합성

- 근거성(groundedness): 답변 문장별로 **원천 문서와의 n-gram 중복·임베딩 유사도로 1차 스크리닝**, 근거 없어 보이는(유사도 하위) 문장은 1차 스크리닝 점수가 낮은 경우에만 **LLM Judge 로 확인**한다.전체 답변을 매번 LLM 으로 채점하지 않는다.
- 위 어휘 중복(n-gram·자카드)·임베딩 유사도 수치가 낮다고 곧장 오답은 아님(재서술 가능성) — 그래서 LLM 확인을 붙이되, 스크리닝 통과분에는 생략한다.
