  변수 (전부 문자열)
    group_names : "본문 k, 요약 k" — 묶음 하나에 한 번씩 들어가는 항목.
    item_names  : "내용 k-j" — 묶음 안에서 j 를 늘려 여러 번 쓰는 항목. 없으면 "없음".
    used_count  : 지금 값이 든 묶음 수.

    max_groups / max_items : 상한. 넘는 번호는 코드가 기각한다.

  (`hwpx_repeat.compact`). 그래서 "2번 빼줘" 를 별도 키 없이 처리한다.
